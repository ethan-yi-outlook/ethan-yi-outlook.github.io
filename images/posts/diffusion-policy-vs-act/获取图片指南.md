# 图片获取指南

由于无法直接从网络下载图片，请按以下方式获取：

## 方法1：从官方项目获取（推荐）

### Diffusion Policy相关图片
访问官方网站：https://diffusion-policy.cs.columbia.edu/
- 下载论文PDF，截取框架图和网络架构图
- 或访问GitHub: https://github.com/real-stanford/diffusion_policy

### ACT相关图片  
访问官方网站：https://tonyzhaozh.github.io/aloha/
- 下载论文PDF，截取相关图表
- 或访问GitHub: https://github.com/tonyzhaozh/act

## 方法2：运行Python脚本生成

安装依赖：
```bash
pip install matplotlib numpy seaborn scikit-learn
```

然后运行：
```bash
cd images/posts/diffusion-policy-vs-act
python generate_all_images.py
```

这将生成：
- noise_schedule.png
- diffusion_process.png  
- cvae_latent_space.png
- attention_map.png
